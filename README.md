# 🧰 jack-tools

Piccoli tool e giochi HTML costruiti da Jack con JackOS, messi online così si aprono da qualsiasi telefono senza avere il Mac acceso.

👉 **https://worldwidejack.github.io/jack-tools/**

| | Tool | Cos'è |
|---|---|---|
| 🏝️ | [Isola dei Gatti](https://worldwidejack.github.io/jack-tools/isola-dei-gatti.html) | Il gioco vibe-codato in vacanza |
| 📐 | [Planimetria camera](https://worldwidejack.github.io/jack-tools/planimetria-camera.html) | La stanza in scala (14,64 m²) — serve al progetto riordino |
| 🧊 | [Camera 3D](https://worldwidejack.github.io/jack-tools/camera-3d.html) | La stessa stanza, girabile |

Il repo è pubblico solo perché GitHub Pages, sul piano gratuito, funziona così.
Dentro non c'è nessun dato personale: niente cognome, niente indirizzo, niente foto. Un `robots.txt` blocca l'indicizzazione sui motori di ricerca.

La roba privata sta in un altro repo, chiuso.
